# 副本输入卡

把下面的卡复制到对话里，逐行填写。**14 个字段必须全部填写**，缺任何一项都不要开始生成。

```text
副本名：
小怪名：
小怪任务名：
BOSS名：
BOSS任务名：
剧情背景：
副本等级范围：
BOSS召唤物数量：
可兑换武器数量：
可兑换装备数量：
武器最低伤害：
武器最高伤害：
装备最低血量：
装备最高血量：
```

## 填写示例

```text
副本名：镜中回廊
小怪名：镜面贵族
小怪任务名：照见自己
BOSS名：伪镜之主
BOSS任务名：撕开这层皮
剧情背景：镜中贵族碎裂时掉落的镜片边缘，刻着别人的脸。它们用完美仿皮复制出你的样子，再逼你承认那只是伪装。
副本等级范围：17000-34000
BOSS召唤物数量：1
可兑换武器数量：2
可兑换装备数量：3
武器最低伤害：25000
武器最高伤害：32000
装备最低血量：10000
装备最高血量：12000
```

## 字段校验

| 字段 | 格式要求 | 不合法时的处理 |
|---|---|---|
| 副本等级范围 | 整数-整数，左小右大 | 要求用户补正，不猜 |
| BOSS召唤物数量 | 整数 ≥1 | 缺省取 1 |
| 可兑换武器数量 | 整数 ≥1 | 缺省取 2 |
| 可兑换装备数量 | 整数 ≥1 | 缺省取 2 |
| 武器最低/最高伤害 | 整数，左小右大 | 要求用户补正 |
| 装备最低/最高血量 | 整数，左小右大 | 要求用户补正 |

配方路径的取舍与成本阶梯见 `SKILL.md` 的「配方选择与成本阶梯」一节：直兑、双材料、两步链三条路径按产物强度自下而上选用。若你想强制某条路径，可在输入卡后追加一行说明，例如「召唤物必须走两步链」。
