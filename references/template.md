# 副本输入卡

九个字段，成对的用半角斜线 `/` 分隔，两侧各留一个空格。

```text
副本名：
小怪名 / 小怪任务名：
BOSS名 / BOSS任务名：
剧情背景：
等级范围：
召唤物数量：
武器数量 / 装备数量：
武器伤害范围：
装备血量范围：
```

## 填写示例

```text
副本名：镜中回廊
小怪名 / 小怪任务名：镜面贵族 / 照见自己
BOSS名 / BOSS任务名：伪镜之主 / 撕开这层皮
剧情背景：镜中贵族碎裂时掉落的镜片边缘，刻着别人的脸。它们用完美仿皮复制出你的样子，再逼你承认那只是伪装。
等级范围：17000-34000
召唤物数量：1
武器数量 / 装备数量：2 / 3
武器伤害范围：25000-32000
装备血量范围：10000-12000
```

## 字段校验

| 字段 | 格式 | 不合法时 |
|---|---|---|
| 等级范围 | 整数-整数，左小右大 | 要求补正，不猜 |
| 召唤物数量 | 整数 ≥1 | 缺省取 1 |
| 武器数量 / 装备数量 | 整数 / 整数 | 缺省取 2 / 2 |
| 武器伤害范围 | 整数-整数，左小右大 | 要求补正 |
| 装备血量范围 | 整数-整数，左小右大 | 要求补正 |

配方路径与成本阶梯见 `SKILL.md` 的「配方选择与成本阶梯」。若要强制某条路径，在输入卡后追加一行说明，例如「召唤物必须走两步链」。
