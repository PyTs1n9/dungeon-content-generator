# 副本内容生成参考

本文件是 `SKILL.md` 的补充样例集。生成前通读一遍，对齐文风、命名密度与配方写法。

## 一、链路速查

```text
小怪 ──掉落──→ 钻币 + 小怪材料（1-2 种）

小怪层 → 召唤物        三条路径任选
  A 直兑     小怪材料 + 钻币
  B 双材料   小怪材料A + 小怪材料B
  C 两步链   小怪材料A + 小怪材料B → 小怪中间物
             小怪中间物 + 钻币 → 召唤物         累计 2 材料 + 货币

BOSS ──掉落──→ 钻币 + BOSS材料（1-2 种）

BOSS 层 → 武器/装备    三条路径任选
  A 直兑     BOSS材料 + 钻币
  B 双材料   BOSS材料A + BOSS材料B
  C 两步链   BOSS材料A + BOSS材料B → BOSS中间物
             BOSS中间物 + 钻币 → 武器/装备      累计 2 材料 + 货币
```

最容易出错的四处：

1. 把「材料A + 材料B + 钻币」写进同一行 —— 非法，单步只有 2 格。
2. 让中间物再参与造中间物 —— 非法，链长上限 2 步。
3. 把小怪材料或小怪中间物写进武器配方 —— 非法，层级隔离。
4. BOSS 材料只有 1 种，却编排了「材料A + 材料B」的配方 —— 材料数不够，改走加量。

## 二、三种路径的取舍

| 路径 | 什么时候用 | 成本档 |
|---|---|---|
| 直兑 | 常规产物，数量占多数 | 低 |
| 双材料 | 中高档产物，需要区分于直兑 | 中 |
| 两步链 | 本副本最高档那一两件 | 高 |

同一副本里不必三条都用。判断标准只有一条：**累计成本与强度正相关**，最贵的一件必须对应最高等级。

## 三、命名对照表

武器与装备的名称是**纯意象词组**，类型词只出现在材质字段。

| 带类型词（错） | 纯意象（对） | 材质 |
|---|---|---|
| 焚天烬灭剑 | 焚天烬灭 | 金剑 |
| 炎魂掘墓镐 | 炎魂掘墓 | 金镐 |
| 霜语裁决斧 | 霜语裁决 | 钻石斧 |
| 焚天王冠 | 焚天临世 | 金头盔 |
| 烬灭战甲 | 烬灭余温 | 金胸甲 |
| 踏火行者之靴 | 踏碎虚影 | 金靴子 |
| 暗影君主之冠 | 暗影君临 | 铁头盔 |
| 夜幕守护胸甲 | 夜幕无痕 | 铁胸甲 |

长度一律 4-6 字。四字为默认，五至六字用于需要更完整意象时。

材料名、中间物名、召唤物名不受此限，可以带「族纹」「残响」「之心」「之核」这类后缀。

## 四、属性白名单速查

**共 22 项：3 个数值属性 + 19 个百分比属性。不得新增。每条属性必须带 `+` 或 `-` 号。**

| 类型 | 属性 | 参考幅度 |
|---|---|---|
| 数值 | 攻击 | `+最小值-最大值`，落在输入区间内 |
| 数值 | 生命 | `+数值`，落在输入区间内 |
| 数值 | 防御 | `+数值` **不带 %**，单件 20 ~ 60 |
| 百分比 | 格挡 | +10% ~ +20% |
| 百分比 | 闪避 | +10% ~ +30% |
| 百分比 | 暴击率 | +25% ~ +45% |
| 百分比 | 暴击伤害 | +20% ~ +60% |
| 百分比 | 首领伤害 | +10% ~ +30% |
| 百分比 | 狂暴 | +10% ~ +25% |
| 百分比 | 斩杀 | +5% ~ +20% |
| 百分比 | 幸运 | +5% ~ +20% |
| 百分比 | 生命提升 | +20% ~ +40% |
| 百分比 | 吸血 | +10% ~ +30% |
| 百分比 | 反弹伤害 | +5% ~ +15% |
| 百分比 | 烧伤 | +5% ~ +40% |
| 百分比 | 减速 | +15% ~ +40% |
| 百分比 | 重度 | +5% ~ +20% |
| 百分比 | 凋零 | +10% ~ +20% |
| 百分比 | 体力流失 | +15% ~ +25% |
| 百分比 | 失明 | +10% ~ +25% |
| 百分比 | 经验加成 | +40% ~ +60% |
| 百分比 | 速度 | +35% ~ +65% |

### 防御换算表

减伤率 = `防御 / (防御 + 100)`，永远小于 100%，不需要担心越界。

| 防御 | 减伤 | 防御 | 减伤 |
|---|---|---|---|
| 20 | 16.7% | 100 | 50.0% |
| 30 | 23.1% | 150 | 60.0% |
| 50 | 33.3% | 200 | 66.7% |
| 80 | 44.4% | 400 | 80.0% |

部位分配：胸甲 40-60 > 护腿 30-45 > 头盔、靴子 20-35。全套四件目标总减伤 45% ~ 70%（总防御 80 ~ 240）。防御边际递减明显，超过 240 后收益低于同位置换生命。

### 负属性

`-` 号表示削弱，是给强力装备附加代价的正常手段。

- 一件装备最多 1 项负属性
- 幅度不超过同件最强正属性的 60%
- 优先选速度、防御、幸运这类通用项
- 只有「打满区间」的那一件才需要配负属性

```text
生命:+12000,速度:-10%,防御:+30,吸血:+12%
```

不存在「冰冻」「中毒」「挖掘速度」这三项，任何情况下都不要写。

## 五、示例 1：镜中回廊（三层路径全用 + 负属性）

**输入**

```text
副本名：镜中回廊
小怪名：镜面贵族
小怪任务名：照见自己
BOSS名：伪镜之主
BOSS任务名：撕开这层皮
剧情背景：镜中贵族碎裂时掉落的镜片边缘，刻着别人的脸。它们用完美仿皮复制出你的样子，再逼你承认那只是伪装。
副本等级范围：17000-34000
BOSS召唤物数量：1
可兑换武器数量：2
可兑换装备数量：3
武器最低伤害：25000
武器最高伤害：32000
装备最低血量：10000
装备最高血量：12000
```

**输出**

```text
【小怪材料】
镜面族纹；玻璃；镜中贵族碎裂时掉落的镜片，边缘刻着别人的脸；掉落:1-2个
完美仿皮；皮革；它们复制的完美外表，摸上去却像一层不属于自己的皮；掉落:1-3个

【小怪中间物】
拟态之皮；皮革；用镜片和仿皮压出的第二层皮，穿上就能骗过同类；配方:镜面族纹×32+完美仿皮×32

【BOSS召唤物】
伪镜之心；唱片(wait)；镜中之主听见了你的呼唤，它准备用你的脸站起来；配方:拟态之皮×1+钻币×50

【BOSS材料】
裂隙余光；萤石粉；伪镜碎裂时漏出的最后一点真实；掉落:1个
空壳残响；末影之眼；被撕开的伪装留下的回声，仍在模仿你的呼吸；掉落:1个

【BOSS中间物】
镜骸；末影珍珠；把两种残响压进一颗珠子里，那张脸在里面慢慢浮起来；配方:裂隙余光×2+空壳残响×2

【武器】
黯淡流星；钻石剑；攻击:+28000-32000,暴击率:+40%,吸血:+25%,速度:+55%；划破镜面的那一瞬，没人看清它的形状；配方:裂隙余光×2+空壳残响×2；等级:28000级
千面归虚；钻石剑；攻击:+26000-30000,暴击率:+35%,闪避:+30%,速度:+50%；所有伪装塌陷之后，只剩这一道；配方:裂隙余光×3+钻币×60；等级:24000级

【装备】
千面归一；金头盔；防御:+30,生命:+12000,闪避:+8%,反弹伤害:+5%,吸血:+12%,经验加成:+55%,速度:-10%；戴上它，镜中再无一物能映出你的脸；配方:镜骸×1+钻币×55；等级:22000级
无人识我；金胸甲；防御:+45,生命:+11800,闪避:+10%,反弹伤害:+7%,吸血:+15%,经验加成:+50%；这层壳由无数张脸压成；配方:裂隙余光×2+空壳残响×2；等级:20000级
踏碎虚影；金靴子；防御:+22,生命:+10500,速度:+35%,闪避:+22%,吸血:+10%；踩碎一地镜片，不发出一点声音；配方:空壳残响×2+钻币×50；等级:17000级
```

**要点拆解**

- 召唤物走两步链：`镜面族纹+完美仿皮 → 拟态之皮`，再 `拟态之皮+钻币 → 伪镜之心`，累计 2 材料 + 货币
- 最高档装备「千面归一」走 BOSS 层两步链，累计成本最高，等级也最高（22000）
- 「千面归一」生命打满 12000 上沿，因此带 `速度:-10%` 作为代价，幅度远低于最强正属性 55%
- 防御按部位分配：胸甲 45 > 头盔 30 > 靴子 22，三件合计 97，换算减伤 `97/197 ≈ 49%`，属合理区间
- 「千面归虚」走直兑，「黯淡流星」走双材料，同一副本内三种路径并存
- 全部属性围绕「闪避 + 吸血」，呼应「看不见的刺杀」主题
- 名称全部 4 字纯意象，类型完全由材质（钻石剑、金头盔、金靴子）表达

## 六、示例 2：火焰之地（BOSS 单材料分支）

**输入**

```text
副本名：火焰之地
小怪名：火焰之身
小怪任务名：玩火自焚
BOSS名：坠炎精灵
BOSS任务名：火钳刘明
剧情背景：火焰之地，火焰之身每烧死一个灵魂，自己也缩小一圈。你穿过火海，看到一个又一个自己在火中挣扎。
副本等级范围：17000-34000
BOSS召唤物数量：1
可兑换武器数量：2
可兑换装备数量：3
武器最低伤害：25000
武器最高伤害：32000
装备最低血量：10000
装备最高血量：12000
```

**输出**

```text
【小怪材料】
赤焰水晶；红石粉；凝聚了魔火元素的水晶，浑身通红，能量骇人；掉落:1-2个
炽热灰烬；烈焰粉；从火焰之身身上飘落的灰烬，仍带着灼热的温度；掉落:1-3个

【BOSS召唤物】
焚心之种；岩浆膏；把火种吞进胸腔，坠炎精灵就会循着热度找来；配方:赤焰水晶×64+钻币×50

【BOSS材料】
炎魔之核；钻石；炎魔力量的核心，握着它会听见火焰在指缝里咆哮；掉落:1个

【武器】
焚天烬灭；金剑；攻击:+28000-32000,烧伤:+40%,吸血:+25%,速度:+55%,防御:+6；万物焚尽，唯余灰烬；配方:炎魔之核×6+钻币×100；等级:28000级
炎魂掘墓；金镐；攻击:+26000-30000,烧伤:+30%,狂暴:+18%,速度:+50%,防御:+8；这把镐子能挖穿大地，直抵炎魔的心脏；配方:炎魔之核×5+钻币×85；等级:24000级

【装备】
焚天临世；金头盔；防御:+30,生命:+12000,烧伤:+8%,反弹伤害:+5%,吸血:+12%,经验加成:+55%,速度:-15%；戴上它，你就是火焰本身；配方:炎魔之核×5+钻币×80；等级:22000级
烬灭余温；金胸甲；防御:+45,生命:+11800,烧伤:+10%,反弹伤害:+7%,吸血:+15%,经验加成:+50%；这件战甲由炎魔的愤怒锻造而成；配方:炎魔之核×4+钻币×70；等级:20000级
踏碎虚影；金靴子；防御:+22,生命:+10500,速度:+35%,闪避:+12%,烧伤:+6%；穿上它，你可以在火海中自由穿行；配方:炎魔之核×2+钻币×50；等级:17000级
```

**要点拆解**

- BOSS 只掉 **1 种**材料，双材料与两步链都不可用，全部改走「直兑 + 加量」
- 加量即梯级：×6 → ×5 → ×5 → ×4 → ×2，数量本身就是稀有度刻度
- 单材料副本允许突破基准数量（×2-3），倍数梯度必须严格单调递减
- 镐类武器「炎魂掘墓」与剑斧走同一套属性，用「狂暴」而非不存在的「挖掘速度」
- 「焚天临世」生命打满 12000，配 `速度:-15%` 作为重甲代价
- 火系属性全部集中在「烧伤」，未混入冰/毒系词条
- 未使用的节（小怪中间物、BOSS 中间物）整体省略，不留空标题

## 七、常见错误清单

| 错误输出 | 问题 | 修正 |
