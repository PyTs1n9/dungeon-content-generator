# 副本内容生成参考

本文件是 `SKILL.md` 的补充样例集。生成前通读一遍，对齐文风、命名密度、颜色分配与指令写法。

## 一、链路速查

```text
小怪 ──掉落──→ 货币 + 小怪材料（1-2 种）

小怪层 → 召唤物        三条路径任选
  A 直兑     小怪材料 + 货币
  B 双材料   小怪材料A + 小怪材料B
  C 两步链   小怪材料A + 小怪材料B → 小怪中间物
             小怪中间物 + 货币 → 召唤物         累计 2 材料 + 货币

BOSS ──掉落──→ 货币 + BOSS材料（1-2 种）

BOSS 层 → 武器/装备    三条路径任选
  A 直兑     BOSS材料 + 货币
  B 双材料   BOSS材料A + BOSS材料B
  C 两步链   BOSS材料A + BOSS材料B → BOSS中间物
             BOSS中间物 + 货币 → 武器/装备      累计 2 材料 + 货币
```

最容易出错的四处：

1. 把「材料A + 材料B + 货币」写进同一行 —— 非法，单步只有 2 格。
2. 让中间物再参与造中间物 —— 非法，链长上限 2 步。
3. 把小怪材料或小怪中间物写进武器配方 —— 非法，层级隔离。
4. BOSS 材料只有 1 种，却编排了「材料A + 材料B」的配方 —— 材料数不够，改走加量。

## 二、命名对照表

武器与装备的名称是**纯意象词组**，类型词只出现在材质字段。

| 带类型词（错） | 纯意象（对） | 材质 |
|---|---|---|
| 焚天烬灭剑 | 焚天烬灭 | 金剑 |
| 炎魂掘墓镐 | 炎魂掘墓 | 金镐 |
| 霜语裁决斧 | 霜语裁决 | 钻石斧 |
| 焚天王冠 | 焚天临世 | 金头盔 |
| 烬灭战甲 | 烬灭余温 | 金胸甲 |
| 踏火行者之靴 | 踏碎虚影 | 金靴子 |
| 暗影君主之冠 | 暗影君临 | 铁头盔 |
| 夜幕守护胸甲 | 夜幕无痕 | 铁胸甲 |

长度一律 4-6 字。材料名、中间物名、召唤物名不受此限。

## 三、指令写法

```text
[钻石剑] 黯淡流星 ｜ 配方:裂隙余光×2+空壳残响×2
/lore name &6&l黯淡流星
/lore add &6攻击:+28000-32000
/lore add &4暴击率:+40%
/lore add &7划破镜面的那一瞬，没人看清它的形状
/lore add &f等级:28000级
```

三条不许破的次序：

1. 首行是 `[材质] 名称 ｜ 掉落/配方`，不带颜色码
2. `/lore name` 在该块最前
3. 武器第一条 `/lore add` 必须是 `&6攻击`，防具必须是 `&6生命`

## 四、属性颜色速查

| 属性 | 颜色 | 参考幅度 | 属性 | 颜色 | 参考幅度 |
|---|---|---|---|---|---|
| 攻击 | `&6` | 输入区间 | 吸血 | `&a` | +10% ~ +30% |
| 生命 | `&6` | 输入区间 | 反弹伤害 | `&e` | +5% ~ +15% |
| 防御 | `&9` | 20 ~ 60 | 烧伤 | `&c` | +5% ~ +40% |
| 格挡 | `&e` | +10% ~ +20% | 减速 | `&9` | +15% ~ +40% |
| 闪避 | `&e` | +10% ~ +30% | 中毒 | `&2` | +5% ~ +25% |
| 暴击率 | `&4` | +25% ~ +45% | 凋零 | `&8` | +10% ~ +20% |
| 暴击伤害 | `&c` | +20% ~ +60% | 体力流失 | `&5` | +15% ~ +25% |
| 首领伤害 | `&4` | +10% ~ +30% | 失明 | `&7` | +10% ~ +25% |
| 狂暴 | `&c` | +10% ~ +25% | 经验加成 | `&d` | +40% ~ +60% |
| 斩杀 | `&6` | +5% ~ +20% | 速度 | `&6` | +35% ~ +65% |
| 幸运 | `&b` | +5% ~ +20% | 生命提升 | `&c` | +20% ~ +40% |

### 同色只能出现一次

按颜色归组，一件物品每一组只能取一个：

| 颜色 | 同色候选 | 每件可选 |
|---|---|---|
| `&6` | 攻击、生命、速度、斩杀 | 1 |
| `&c` | 暴击伤害、狂暴、生命提升、烧伤 | 1 |
| `&e` | 格挡、闪避、反弹伤害 | 1 |
| `&4` | 暴击率、首领伤害 | 1 |
| `&9` | 防御、减速 | 1 |
| `&a` | 吸血 | 1 |
| `&b` | 幸运 | 1 |
| `&2` | 中毒 | 1 |
| `&8` | 凋零 | 1 |
| `&5` | 体力流失 | 1 |
| `&7` | 失明 | 1 |
| `&d` | 经验加成 | 1 |

武器必带攻击、防具必带生命，两者都是 `&6`，所以 **`&6` 那一格永远被占满，速度与斩杀在武器/防具上不会出现**。这是规则的必然结果。

### 防御换算

减伤率 = `防御 / (防御 + 100)`。

| 防御 | 减伤 | 防御 | 减伤 |
|---|---|---|---|
| 20 | 16.7% | 100 | 50.0% |
| 30 | 23.1% | 150 | 60.0% |
| 50 | 33.3% | 200 | 66.7% |
| 80 | 44.4% | 400 | 80.0% |

部位分配：胸甲 40-60 > 护腿 30-45 > 头盔、靴子 20-35。全套四件总减伤 45% ~ 70%。超过 240 后改堆生命。

## 七、常见错误清单

| 错误输出 | 问题 | 修正 |
|---|---|---|
| `/lore add &6攻击:+28000-32000` 不在第一行 | 攻击/生命必须置顶 | 移到该块第一条 add |
| `&6速度:+50%` 与 `&6攻击` 同件 | 同色互斥 | 去掉速度，改 `&b幸运` 或 `&a吸血` |
| `&c烧伤` 与 `&c狂暴` 同件 | 同色互斥 | 只留一个 |
| `钻币×50` / `金币×50` | 货币名不统一 | 一律写 `货币×50` |
| `焚天烬灭剑；金剑；攻击:+28000` | 未使用 lore 指令 | 改为 `[金剑] 焚天烬灭` + 指令行 |
| `防御:+20%` | 防御是数值属性 | `防御:+20` |
| 头盔 防御:+300 | 单件超 60 | 按部位分配，超额改堆生命 |
| 冰冻 / 挖掘速度 | 属性不存在 | 用 22 项白名单内的 |
| `生命:-5000` 无最强正属性支撑 | 负属性无代价依据 | 只给打满区间的那件配负属性 |
| 炎魔之核×2+叛逆之心×2+货币×30 | 单步三格 | 拆两步，或去掉货币 |
| 望远镜；粉末雪桶 | 非 1.8.8 物品 | 改用玻璃、雪球 |
| 等级:45000级（区间 17000-34000） | 超出等级范围 | 收进区间内 |
