# 副本内容生成参考

本文件是 `SKILL.md` 的补充样例集。生成前通读一遍，对齐文风、命名密度、颜色分配与指令写法。

## 一、链路速查

```text
小怪 ──掉落──→ 货币 + 小怪材料（1-2 种）

小怪层 → 召唤物        三条路径任选
  A 直兑     小怪材料 + 货币
  B 双材料   小怪材料A + 小怪材料B
  C 两步链   小怪材料A + 小怪材料B → 小怪中间物
             小怪中间物 + 货币 → 召唤物         累计 2 材料 + 货币

BOSS ──掉落──→ 货币 + BOSS材料（1-2 种）

BOSS 层 → 武器/装备    三条路径任选
  A 直兑     BOSS材料 + 货币
  B 双材料   BOSS材料A + BOSS材料B
  C 两步链   BOSS材料A + BOSS材料B → BOSS中间物
             BOSS中间物 + 货币 → 武器/装备      累计 2 材料 + 货币
```

最容易出错的四处：

1. 把「材料A + 材料B + 货币」写进同一行 —— 非法，单步只有 2 格。
2. 让中间物再参与造中间物 —— 非法，链长上限 2 步。
3. 把小怪材料或小怪中间物写进武器配方 —— 非法，层级隔离。
4. BOSS 材料只有 1 种，却编排了「材料A + 材料B」的配方 —— 材料数不够，改走加量。

## 二、命名对照表

武器与装备的名称是**纯意象词组**，类型词只出现在材质字段。

| 带类型词（错） | 纯意象（对） | 材质 |
|---|---|---|
| 焚天烬灭剑 | 焚天烬灭 | 金剑 |
| 炎魂掘墓镐 | 炎魂掘墓 | 金镐 |
| 霜语裁决斧 | 霜语裁决 | 钻石斧 |
| 焚天王冠 | 焚天临世 | 金头盔 |
| 烬灭战甲 | 烬灭余温 | 金胸甲 |
| 踏火行者之靴 | 踏碎虚影 | 金靴子 |

长度一律 4-6 字。材料名、中间物名、召唤物名不受此限。

## 三、格式骨架

**材料 / 中间物 / 召唤物**

```text
[材质] 名称 ｜ 掉落:N个
/lore name &b名称 &7[&a>>T<<&7]
/lore add &a介绍 &e---&6>>
/lore add &a
/lore add &a第一句描述
/lore add &9第二句描述
```

**武器 / 装备**

```text
[材质] 名称 ｜ 配方:...
/lore name &4&l名称 &7[&a>>T<<&7]
/lore add &a属性 &e---&6>>
/lore add &a
/lore add &c攻击： &f+最小值-最大值
/lore add &颜色属性名：&f+数值%
/lore add &a
/lore add &a介绍 &e---&6>>
/lore add &a
/lore add &a第一句描述
/lore add &9第二句描述
/lore add &a
/lore add &a使用条件 &e---&6>>
/lore add &a
/lore add &c等级： &fNNNNN
```

三条不许破的次序：

1. `/lore name` 在块内最前
2. 武器第一条属性是 `&c攻击：`，防具是 `&c生命：`
3. 五个空行 `&加a` 缺一个都会让版面塌掉

## 四、属性颜色速查

| 属性 | 颜色 | 参考幅度 | 属性 | 颜色 | 参考幅度 |
|---|---|---|---|---|---|
| 攻击 | `&c` | 输入区间 | 吸血 | `&a` | +1% ~ +20% |
| 生命 | `&c` | 输入区间 | 反弹伤害 | `&e` | +1% ~ +20% |
| 防御 | `&9` | 20 ~ 60 | 烧伤 | `&c` | +1% ~ +20% |
| 格挡 | `&3` | +1% ~ +15% | 减速 | `&9` | +1% ~ +20% |
| 闪避 | `&e` | +1% ~ +15% | 中毒 | `&2` | +1% ~ +20% |
| 暴击率 | `&4` | +5% ~ +30% | 凋零 | `&8` | +1% ~ +20% |
| 暴击伤害 | `&1` | +5% ~ +50% | 体力流失 | `&5` | +1% ~ +20% |
| 首领伤害 | `&4` | +10% ~ +30% | 失明 | `&7` | +1% ~ +20% |
| 狂暴 | `&c` | +10% ~ +25% | 经验加成 | `&d` | +10% ~ +50% |
| 斩杀 | `&6` | +1% ~ +5% | 速度 | `&6` | +35% ~ +65% |
| 幸运 | `&b` | +5% ~ +20% | 生命提升 | `&c` | +1% ~ +20% |

### 相邻两行不同色

颜色可以重复使用，**只要不连续**。

```text
合法：  &c攻击 / &4暴击率 / &c烧伤 / &6速度 / &9防御
非法：  &c攻击 / &c烧伤
```

`&c` 同时承载攻击与烧伤、生命与暴击伤害，`&6` 同时承载速度与斩杀，中间插一条其他颜色即可。

描述第二行默认用 `&9`，若该行紧邻的属性已是 `&9`，改用 `&d`。

### 防御换算

减伤率 = `防御 / (防御 + 100)`。

| 防御 | 减伤 | 防御 | 减伤 |
|---|---|---|---|
| 20 | 16.7% | 100 | 50.0% |
| 30 | 23.1% | 150 | 60.0% |
| 50 | 33.3% | 200 | 66.7% |
| 80 | 44.4% | 400 | 80.0% |

部位分配：胸甲 40-60 > 护腿 30-45 > 头盔、靴子 20-35。全套四件总减伤 45% ~ 70%。超过 240 后改堆生命。
